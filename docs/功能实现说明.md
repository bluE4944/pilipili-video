## 二、核心功能实现

### 1. 本地文件夹配置与视频读取

#### 实现位置
- `src/store/folder.ts`: 文件夹配置状态管理
- `src/views/SettingsView.vue`: 配置界面
- `src/utils/videoScanner.ts`: 视频扫描逻辑

#### 实现逻辑

**文件夹配置**:
```typescript
// 使用 localStorage 存储配置
// 支持添加、删除、编辑、启用/禁用
const folders = ref<FolderConfig[]>([])
```

**视频扫描**:
1. **文件识别**: 通过文件扩展名判断是否为视频文件（.mp4, .mkv, .avi 等）
2. **合集整合**: 
   - 使用字符串相似度算法（Levenshtein距离）判断文件名是否相似
   - 提取集数标识（如 "01", "第1集", "EP01"）
   - 按集数排序
3. **元信息提取**:
   - 文件名、大小、修改时间从 File 对象获取
   - 视频时长通过创建 video 元素读取 metadata

**注意**: 由于浏览器安全限制，无法直接访问本地文件系统。当前实现：
- 通过文件选择器让用户手动选择视频文件
- 文件存储在内存中（Map），通过 Blob URL 播放
- 元数据存储在 IndexedDB
- 预留接口，后续可通过 Electron 或后端 API 实现自动扫描

## 三、关键技术点

### 1. 视频文件管理

由于浏览器无法直接访问文件系统，采用以下方案：

```typescript
// 文件缓存（内存）
const fileCache = new Map<string, File>()

// 注册文件（从文件选择器）
registerVideoFile(videoId, file)

// 创建 Blob URL 用于播放
const blobUrl = URL.createObjectURL(file)
```

**注意事项**:
- Blob URL 需要在使用后释放，避免内存泄漏
- 文件对象存储在内存中，刷新页面会丢失
- 后续可通过 IndexedDB 存储文件数据（但容量有限）

### 2. 视频合集识别

使用字符串相似度算法：

```typescript
// Levenshtein 距离算法
function levenshteinDistance(str1: string, str2: string): number

// 相似度计算
const similarity = (longer.length - distance) / longer.length
// 相似度 > 0.6 认为是同一合集
```

**提取集数**:
- 正则匹配常见格式：`第1集`、`EP01`、`[01]`、`-01-` 等
- 按集数排序，确保播放顺序正确

### 3. 播放记录持久化

```typescript
// 保存到 localStorage
localStorage.setItem('playRecords', JSON.stringify(records))

// 加载时恢复
const records = JSON.parse(localStorage.getItem('playRecords'))
```

**优化**:
- 每5秒保存一次，避免频繁写入
- 播放结束时立即保存
- 切换视频时保存当前记录

### 4. IndexedDB 使用

```typescript
// 数据库结构
interface VideoDB {
  videos: { id, name, path, size, ... }
  collections: { id, title, videoIds, ... }
  comments: { id, videoId, content, ... }
}

// 使用 idb 库简化操作
import { openDB } from 'idb'
const db = await openDB<VideoDB>('pilipili-video-db', 1)
```

## 五、性能优化

1. **路由懒加载**: 使用动态 import 加载页面组件
2. **组件按需加载**: Naive UI 支持 Tree-shaking
3. **播放记录节流**: 5秒保存一次，避免频繁写入
4. **Blob URL 管理**: 及时释放，避免内存泄漏
5. **视频列表虚拟滚动**: 大量视频时可使用虚拟列表（待实现）

## 六、已知限制

1. **文件系统访问**: 浏览器无法直接访问本地文件夹，需要通过文件选择器
2. **文件持久化**: 刷新页面后需要重新选择文件
3. **视频格式支持**: 依赖浏览器原生支持，部分格式可能需要转码
4. **弹幕功能**: 暂未实现，Video.js 支持插件扩展

## 七、后续优化方向

1. **Electron 集成**: 包装为桌面应用，支持直接访问文件系统
2. **后端 API**: 实现文件扫描、用户认证、评论存储等服务
3. **视频转码**: 后端提供转码服务，统一视频格式
4. **弹幕系统**: 集成弹幕插件，支持弹幕发送和显示
5. **视频预览**: 生成视频缩略图，提升用户体验
6. **搜索功能**: 全文搜索视频标题、描述等
7. **播放列表**: 支持自定义播放列表
8. **字幕支持**: 支持外挂字幕文件
