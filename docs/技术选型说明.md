# 技术选型说明

## 一、基础框架

### Vue3 + TypeScript
- **版本**: Vue 3.3.4 + TypeScript 5.2.2
- **选择理由**:
  - Vue3 组合式 API 提供更好的代码组织和复用性
  - TypeScript 提供类型安全，减少运行时错误
  - 更好的开发体验和代码提示
  - 性能优化（Composition API、Tree-shaking）

## 二、UI 框架

### Naive UI
- **版本**: 2.34.3
- **选择理由**:
  1. **Vue3 + TypeScript 原生支持**: Naive UI 专为 Vue3 设计，完全使用 TypeScript 编写，提供完整的类型定义
  2. **B站风格适配**: 
     - 组件设计简洁现代，符合 B站 的视觉风格
     - 支持深色/浅色主题切换
     - 组件样式可高度自定义
  3. **功能完整**: 提供丰富的组件库（表格、表单、对话框、消息提示等）
  4. **性能优秀**: 按需加载，Tree-shaking 友好
  5. **文档完善**: 中文文档齐全，示例丰富

**对比其他框架**:
- Element Plus: 功能强大但风格偏企业级，不如 Naive UI 接近 B站风格
- Arco Design Vue: 同样优秀，但 Naive UI 的 API 设计更简洁
- Ant Design Vue: Vue3 版本更新较慢，TypeScript 支持不如 Naive UI

## 三、视频播放插件

### Video.js
- **版本**: 8.6.1
- **选择理由**:
  1. **成熟稳定**: 业界广泛使用的开源视频播放器，经过大量项目验证
  2. **功能完整**:
     - 支持本地视频播放（File/Blob URL）
     - 支持进度记忆（通过 currentTime API）
     - 支持倍速播放、音量控制、全屏等
     - 丰富的插件生态
  3. **自定义性强**: 可以通过插件扩展功能（如弹幕、字幕等）
  4. **兼容性好**: 支持主流浏览器和视频格式
  5. **文档完善**: 官方文档详细，社区活跃

**对比其他插件**:
- Plyr: 更轻量但功能相对较少，插件生态不如 Video.js
- Vue3-video-play: Vue3 专用但功能有限，不如 Video.js 成熟
- DPlayer: 主要面向在线视频，本地播放支持不如 Video.js

## 四、状态管理

### Pinia
- **版本**: 2.1.7
- **选择理由**:
  - Vue3 官方推荐的状态管理库
  - 支持 TypeScript，类型推断完善
  - API 简洁，学习成本低
  - 支持组合式 API，与 Vue3 完美配合
  - 支持 DevTools 调试

## 五、路由管理

### Vue Router 4
- **版本**: 4.2.5
- **选择理由**:
  - Vue3 官方路由库
  - 完全支持 TypeScript
  - 组合式 API 支持
  - 性能优化（路由懒加载）

## 六、数据存储

### IndexedDB (idb)
- **版本**: 7.1.1
- **选择理由**:
  - 浏览器原生数据库，存储容量大（通常几GB）
  - 适合存储视频元数据、评论等结构化数据
  - idb 库提供 Promise API，使用方便
  - 支持索引查询，性能好

### localStorage
- **用途**: 存储用户配置、播放记录、主题设置等小数据
- **选择理由**: 简单易用，适合键值对存储

## 七、工具库

### dayjs
- **版本**: 1.11.10
- **用途**: 日期时间格式化
- **选择理由**: 轻量级，API 简洁，替代 moment.js

### axios
- **版本**: 1.6.2
- **用途**: HTTP 请求（为后续前后端分离预留）
- **选择理由**: 功能强大，支持拦截器，TypeScript 支持好

## 八、构建工具

### Vue CLI 5
- **选择理由**:
  - 官方推荐，配置完善
  - 支持 TypeScript、Sass/SCSS
  - 开发服务器热更新
  - 生产构建优化

## 九、浏览器兼容性

- Chrome/Edge: 完全支持
- Firefox: 完全支持
- Safari: 基本支持（部分 API 可能需要 polyfill）

## 十、后续扩展建议

1. **文件系统访问**: 
   - 使用 Electron 包装为桌面应用
   - 或使用 File System Access API（需要用户授权）

2. **后端 API**:
   - 预留接口设计，可轻松替换为 API 调用
   - 建议使用 Node.js + Express 或 Python + FastAPI

3. **弹幕功能**:
   - Video.js 支持插件扩展
   - 可使用 videojs-danmu 等插件

4. **视频转码**:
   - 后端实现视频转码服务
   - 支持多种格式和分辨率
