# 运行说明

## 一、环境要求

- Node.js: >= 16.0.0
- npm: >= 7.0.0 或 yarn >= 1.22.0
- 现代浏览器（Chrome、Edge、Firefox、Safari）

## 二、安装依赖

```bash
# 使用 npm
npm install

# 或使用 yarn
yarn install
```

## 三、开发环境运行

```bash
# 启动开发服务器
npm run serve

# 或
yarn serve
```

开发服务器默认运行在 `http://localhost:8080`

### 开发服务器配置

如需修改端口或其他配置，可在 `vue.config.js` 中修改：

```javascript
module.exports = {
  devServer: {
    port: 8080,
    host: '0.0.0.0' // 允许局域网访问
  }
}
```

## 四、局域网访问

### 方法一：修改开发服务器配置

1. 修改 `vue.config.js`:
```javascript
module.exports = {
  devServer: {
    port: 8080,
    host: '0.0.0.0', // 监听所有网络接口
    allowedHosts: 'all' // 允许所有主机访问
  }
}
```

2. 重启开发服务器

3. 在同一局域网的其他设备上访问：
   - `http://[你的IP地址]:8080`
   - 例如：`http://192.168.1.100:8080`

### 方法二：使用生产构建

1. 构建项目：
```bash
npm run build
```

2. 使用静态文件服务器（如 `serve`、`http-server`）：
```bash
# 安装 serve
npm install -g serve

# 启动服务器
serve -s dist -l 8080 --host 0.0.0.0
```

3. 在同一局域网的其他设备上访问服务器地址

## 六、使用说明

### 1. 首次使用

1. 启动应用后，默认以游客身份登录
2. 进入"视频"页面，点击"添加视频"按钮
3. 选择本地视频文件（支持多选）
4. 系统会自动识别并整合为视频合集

### 2. 播放视频

1. 在视频列表页点击视频卡片
2. 进入视频详情页，自动加载播放记录（如有）
3. 点击分集列表切换不同集数
4. 播放完成后自动切换到下一集

### 3. 配置文件夹

1. 进入"设置"页面
2. 在"文件夹配置"中添加文件夹路径
3. 注意：由于浏览器限制，当前版本需要通过文件选择器添加视频
4. 文件夹配置为后续扩展预留，实际扫描需要后端支持

### 4. 主题切换

1. 点击顶部导航栏的主题切换按钮
2. 或在设置页面选择主题模式（浅色/深色/跟随系统）

### 5. 账号功能

1. 点击顶部导航栏的用户按钮
2. 选择"登录"或"注册"
3. 或使用"游客模式"（无需注册）

### 6. 评论功能

1. 在视频详情页底部找到评论区
2. 输入评论内容，点击"发表评论"
3. 评论会保存在本地（IndexedDB）

## 七、常见问题

### Q: 无法播放视频？
A: 
1. 确保视频格式被浏览器支持（推荐使用 MP4）
2. 检查浏览器控制台是否有错误信息
3. 尝试重新添加视频文件

### Q: 刷新页面后视频不见了？
A: 由于浏览器安全限制，文件对象无法持久化。刷新页面后需要重新添加视频文件。元数据（视频信息）会保留在 IndexedDB 中。

### Q: 如何实现真正的文件夹扫描？
A: 
1. 使用 Electron 包装为桌面应用
2. 或配置后端 API，通过服务器扫描文件系统
3. 或使用 File System Access API（需要用户授权，Chrome/Edge 支持）

### Q: 播放记录丢失？
A: 播放记录存储在 localStorage，清除浏览器数据会导致丢失。建议定期导出数据或使用后端存储。

### Q: 局域网访问时样式异常？
A: 确保所有设备在同一局域网，检查防火墙设置，确保端口未被阻止。

## 八、部署建议

### 静态部署

1. 构建项目：`npm run build`
2. 将 `dist/` 目录部署到静态服务器（Nginx、Apache、CDN等）
3. 配置服务器支持 SPA 路由（所有路由指向 index.html）

### Nginx 配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /path/to/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

### Docker 部署（可选）

```dockerfile
FROM nginx:alpine
COPY dist/ /usr/share/nginx/html/
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

## 十、性能优化建议

1. **生产构建**: 使用 `npm run build` 构建生产版本，启用代码压缩和优化
2. **CDN 加速**: 将静态资源部署到 CDN
3. **HTTP/2**: 使用 HTTP/2 协议提升加载速度
4. **缓存策略**: 配置适当的缓存策略（静态资源长期缓存，HTML 不缓存）

## 十一、安全注意事项

1. **XSS 防护**: 用户输入内容需要转义（Vue 默认处理）
2. **CSRF 防护**: 后续添加后端 API 时需配置 CSRF Token
3. **文件上传限制**: 限制文件大小和类型
4. **敏感信息**: 不要在前端存储敏感信息（密码等）

2. **Electron**: 包装为桌面应用，支持文件系统访问
3. **PWA**: 添加 Service Worker，支持离线访问
4. **视频转码**: 后端提供转码服务，统一视频格式
